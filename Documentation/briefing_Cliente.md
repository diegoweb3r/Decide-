# 📋 Brief de Produto — **Decide!**

Olá, Gemini. Sou o **Cliente / Product Owner** deste projeto. A ideia é desenvolver um Web App simples para ajudar pessoas indecisas a escolher entre diferentes opções do dia a dia.

## 1. Nome e objetivo

**Nome:** Decide!

**Objetivo:** criar uma ferramenta rápida onde o usuário possa cadastrar algumas opções e deixar o aplicativo escolher uma delas aleatoriamente.

Exemplo:

> "Não sei qual filme assistir."
> → adiciono 5 filmes
> → clico em **Decidir!**
> → o aplicativo escolhe um filme.

A experiência deve ser simples, divertida e visualmente agradável.

## 2. Público-alvo e problema

**Público-alvo:** pessoas que têm dificuldade para tomar pequenas decisões do cotidiano.

**Problema:** muitas vezes temos várias opções e acabamos perdendo tempo tentando decidir algo simples, como:

* Qual filme assistir?
* O que comer?
* Onde sair?
* Qual tarefa fazer primeiro?
* Qual jogo jogar?

O app deve transformar essa decisão em algo rápido e descontraído.

## 3. Funcionalidades essenciais — MVP

1. **Adicionar opções**

   * O usuário deve conseguir inserir uma opção por vez em uma lista.

2. **Visualizar e remover opções**

   * As opções cadastradas devem aparecer claramente na tela.
   * O usuário deve conseguir excluir uma opção.

3. **Botão "Decidir!"**

   * Ao clicar, o sistema deve escolher aleatoriamente uma das opções cadastradas.

4. **Exibir o resultado**

   * A opção escolhida deve receber bastante destaque visual para deixar claro qual foi a decisão.

5. **Limpar a lista**

   * O usuário deve conseguir remover todas as opções e começar uma nova decisão.

## 4. Critérios de sucesso

Para eu considerar o MVP aprovado:

* Deve ser possível **adicionar, visualizar e remover opções**.
* O botão **"Decidir!"** deve selecionar uma opção da lista de forma aleatória.
* O resultado precisa ser **visualmente destacado**.
* O usuário deve receber algum feedback caso tente decidir sem ter opções cadastradas.
* Deve ser possível **reiniciar a lista** facilmente.
* A interface precisa funcionar bem tanto em **desktop quanto em celular**.
* A experiência deve ser simples: um usuário novo deve entender como usar o aplicativo sem precisar de instruções.

### Fora do escopo do MVP

Não preciso, inicialmente, de login, banco de dados, cadastro de usuários, integração com APIs ou funcionalidades sociais.

Quero algo pequeno, funcional e bem acabado. O objetivo é validar a ideia com uma primeira versão.
